HONEST MATERIALS · WHAT THIS SHEET IS MADE OF, AND WHAT IT REFUSES TO DO

Nothing is invented

A unit is printed only where Home Assistant published one in the discovery config. A channel that has never published shows not published, not a zero. A board that is offline shows the word offline in the large slot, and any value it left behind is labelled LAST with its age — never presented as current.

The joints are visible

Under every row is the exact MQTT topic the value arrived on, and where a discovery config described it, that config topic too. The board identity in the panel header is parsed out of state_topic, because the published name is “PM2.5” on every board and cannot tell them apart.

Bounded subscriptions

Five topic patterns, all authored here: two discovery shapes, board availability, the PM2.5 topic, and the ESPHome sensor shape. No pattern contains a multi-level wildcard, and a topic that arrives inside a payload is never trusted with a wildcard of its own.

One dependency

The MQTT client is mqtt@5.15.2, pinned by version and locked by integrity hash. Everything else — layout, parsing, banding — is in this one file. No build step, no framework, no analytics, no fonts fetched.

Reading a panel. The big number is PM2.5 in µg/m³, the one value the EPA scale below governs. The table beneath it is everything else the board publishes, in a fixed order, so a panel always looks the same and a missing row is visible as a missing row.
Panel order never changes. Boards are laid out by id, ascending. An offline board keeps its slot — hatched and dashed — instead of vanishing, because a wall that quietly drops a dead sensor is a wall that lies about how many sensors there are.
Demo mode. Adding ?demo= to the address — a number, a band name, cycle or mixed — draws three invented boards so a layout can be judged at values the fleet is not reporting today. It opens no connection at all, stores nothing, and marks every panel and the top of the page until it is reloaded away. Without that parameter nothing on this sheet is simulated.
Privacy. Broker settings live in this browser’s local storage on this device only, and go nowhere but to the broker itself. Press S to see or change them, Esc to close.
