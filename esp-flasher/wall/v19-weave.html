Broker

This wall speaks MQTT over WebSocket. A browser cannot open the plain TCP listener, so this must be the WebSocket port — pointing it at the wrong one fails in a way that looks exactly like a bad passphrase.

How this wall is woven

The cloth is the reading. Thread pitch and thread width are computed from the number itself — clean air weaves an open plain-weave you can see the ground through, and every microgram packs the sett tighter until no light passes. Nothing here is hand-picked, and no colour is doing the work.

An empty loom is not a zero. A board that has reported offline shows bare warp: threads strung up, nothing crossing them, no number. This wall never weaves cloth out of a reading it does not have, and never lets a stale number stand in for a live one.

Boards name themselves. Every panel is titled with the board id parsed out of its own state topic. The discovery payload calls all three of them “PM2.5”, so the published name is never allowed to be the identity.

Freshly opened. Readings are published without the retain flag, so a page that has just loaded shows threaded — waiting for the first pick even for a perfectly healthy board. Nothing is stored unless you save it above, and then only in this browser on this device.
